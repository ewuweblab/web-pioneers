Web Pioneers

Tim Berners-Lee

Invented the World Wide Web at CERN in 1989, creating HTML, URLs and HTTP. Founded the W3C in 1994 and co-founded the Open Data Institute.

w3.org/People/Berners-Lee

Jeffrey Zeldman

Co-founded A List Apart and led the Web Standards Project. Wrote Designing with Web Standards and co-founded the An Event Apart conference.

zeldman.com

Nicole Sullivan

Created Object-Oriented CSS (OOCSS) for scalable, reusable stylesheets. Known for front-end performance work at Yahoo! and Facebook.

stubbornella.org

Molly Holzschlag

Author of 35 books on web design, including The Zen of CSS Design. Led the Web Standards Project (2004–2006) and championed accessibility and education. (1963–2023)

molly.com

Eric Meyer

Early CSS champion and author of CSS: The Definitive Guide. Co-founded An Event Apart and created the S5 slideshow format.

meyerweb.com

Lynda Weinman

Wrote Designing Web Graphics (1996), one of the first web design books. Co-founded lynda.com, the online learning site LinkedIn bought in 2015.

Wikipedia: Lynda Weinman
